Todo List

Приложение для списка задач на C# и WPF (.NET 10).

Запуск на Windows:
Откройте папку проекта в VS Code и выполните в терминале:
dotnet run

Работа с задачами:
Заполните поля и нажмите «Добавить».
Выберите задачу из списка, чтобы изменить её или удалить.
Кнопка «Сохранить JSON» записывает задачи в файл tasks.json.
При следующем запуске приложение предложит загрузить задачи.

Основные классы:
TodoModel — данные задачи и проверка значений.
TodoService — добавление, изменение и удаление задач.
ITaskRepository — интерфейс сохранения и загрузки.
JsonTaskRepository — сохранение и загрузка файла JSON.
